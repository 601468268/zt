使用 ECharts 5.5.1 绘制两个交互式图表： ① 折线图——近一周智能客服与人工坐席的会话量趋势（平滑曲线 + 渐变面积）； ② 饼图（环形）——用户咨询问题类型占比。 两个图表均支持鼠标悬停查看数值、点击图例显示 / 隐藏系列，窗口变化时自动重绘。 ECharts 库文件已下载到本地 cdn/echarts.min.js，无需联网即可运行。

二、核心代码
1引入本地 ECharts 并初始化
<script src="cdn/echarts.min.js"></script> // 每个图表：先取容器，再 init，最后 setOption var chart = echarts.init(document.querySelector('.zt-chart-line')); chart.setOption(option); window.addEventListener('resize', function () { chart.resize(); });
2折线图：双系列 + 渐变面积
option = { tooltip: { trigger: 'axis' }, legend: { data: ['智能客服', '人工坐席'] }, xAxis: { type: 'category', boundaryGap: false, data: days }, yAxis: { type: 'value' }, series: [{ name: '智能客服', type: 'line', smooth: true, data: aiData, areaStyle: { // 渐变面积填充 color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [ { offset: 0, color: 'rgba(52,152,219,.45)' }, { offset: 1, color: 'rgba(52,152,219,.02)' } ]) } }] };
3环形饼图：半径与标签
series: [{ name: '问题类型', type: 'pie', radius: ['42%', '68%'], // 内外半径不同 → 环形 itemStyle: { borderRadius: 6, borderColor: '#fff', borderWidth: 2 }, label: { formatter: '{b}\n{d}%' }, data: [ { value: 32, name: '订单物流' }, { value: 24, name: '售后退换' } ] }]
三、知识点小结
init 与 setOption

echarts.init 把容器变成画布，setOption 传入配置对象；更新数据只需再次 setOption，ECharts 会自动做差量动画。

series.type

同一个配置里 series 可以是数组，放多个系列即可实现多线对比；type 决定图表类型（line / pie / bar …）。

tooltip 与 legend

trigger:'axis' 让提示框按整列显示；legend 自动生成可点击的系列开关。

响应式 resize

ECharts 画布不会自动跟随容器，需要监听 window 的 resize 事件手动调用 chart.resize()。
