JavaScript 程序由三种基本结构组成：顺序结构（从上到下依次执行）、 条件结构（根据判断结果选择执行分支）、循环结构（满足条件时重复执行）。 本页所有运行结果均由 JavaScript 真实计算后写入页面，打开浏览器控制台（F12）可查看完整输出。
一、顺序结构（默认结构）
1从上到下，一行一行执行
先声明半径，再声明圆周率，然后计算面积，最后输出——语句按书写顺序执行。
var zt_r = 5; // 第1步：半径 var zt_pi = 3.14159; // 第2步：圆周率 var zt_area = zt_pi * zt_r * zt_r; // 第3步：计算面积 console.log('圆面积：' + zt_area.toFixed(2)); // 第4步：输出

二、条件结构（分支结构）
2-1if 单分支
条件为 true 才执行大括号里的代码。
var zt_age = 20; if (zt_age >= 18) { console.log('已成年，可以进入'); }

2-2if...else 双分支
二选一：条件成立走 if，否则走 else。
var zt_n = 7; if (zt_n % 2 === 0) { console.log(zt_n + ' 是偶数'); } else { console.log(zt_n + ' 是奇数'); }
运行结果：
2-3if...else if...else 多分支
成绩分级：90 以上优秀、80 以上良好、60 以上及格、其余不及格。
var zt_score = 86; if (zt_score >= 90) { zt_level = '优秀'; } else if (zt_score >= 80) { zt_level = '良好'; } else if (zt_score >= 60) { zt_level = '及格'; } else { zt_level = '不及格'; }

2-4switch 多分支
把一个变量和多个 case 值做全等比较，注意每个 case 后要写 break。
var zt_day = 3; switch (zt_day) { case 1: zt_name = '星期一'; break; case 2: zt_name = '星期二'; break; case 3: zt_name = '星期三'; break; case 4: zt_name = '星期四'; break; case 5: zt_name = '星期五'; break; default: zt_name = '周末'; }

三、循环结构（重复结构）
3-1for 循环
三要素：初始值; 循环条件; 变量更新。下面求 1+2+...+100。
var zt_sum = 0; for (var i = 1; i <= 100; i++) { zt_sum += i; }
运行结果：
3-2while 循环
先判断条件再执行，条件不成立一次都不执行。下面求 1~50 的偶数和。
var zt_even = 0, zt_i = 2; while (zt_i <= 50) { zt_even += zt_i; zt_i += 2; }
运行结果：
3-3do...while 循环
先执行一次再判断，所以循环体至少执行一次。
var zt_k = 1; do { zt_k++; } while (zt_k < 1); // 条件一开始就是假的
运行结果：
3-4for...in 遍历对象
for...in 拿到的是键名（属性名 / 下标）。
var zt_stu = { zt_name: '张涛', zt_age: 18, zt_class: '软件工程' }; for (var zt_key in zt_stu) { console.log(zt_key + '：' + zt_stu[zt_key]); }
运行结果：
3-5for...of 遍历数组
for...of 直接拿到元素值，比 for...in 更适合数组。
var zt_lang = ['HTML', 'CSS', 'JavaScript']; for (var zt_item of zt_lang) { console.log(zt_item); }
运行结果：
3-6break 与 continue
break 跳出整个循环；continue 跳过本次循环，直接进入下一次。
// break：找到第一个能被 9 整除且大于 50 的数 for (var i = 51; i <= 100; i++) { if (i % 9 === 0) { zt_hit = i; break; } } // continue：只输出 1~10 中的奇数 for (var j = 1; j <= 10; j++) { if (j % 2 === 0) { continue; } zt_odd += j + ' '; }

3-7循环的嵌套 —— 九九乘法表
外层循环控制行（1~9），内层循环控制列（1~当前行），每层都用到循环变量。
for (var i = 1; i <= 9; i++) { // 外层：行 for (var j = 1; j <= i; j++) { // 内层：列 zt_html += j + '×' + i + '=' + (i * j) + ' '; } zt_html += '\n'; }
