三、操作 class 与样式（交互一）
3-1classList：add / remove / toggle / contains
toggle 表示"有就删、没有就加"，做开关效果最方便；contains 用来判断有没有某个 class。
var zt_box = document.querySelector('.zt-style-box'); zt_box.classList.add('zt-highlight'); // 添加 zt_box.classList.remove('zt-highlight'); // 移除 zt_box.classList.toggle('zt-highlight'); // 切换（开关） zt_box.classList.contains('zt-highlight'); // 判断是否包含

四、增删改节点（交互二 · 事件委托）
4-1创建与插入：createElement + appendChild / insertBefore
创建元素 → 设置内容与 class → 挂到父节点上；insertBefore(新节点, 参照节点) 可插到最前面。
var zt_li = document.createElement('li'); // 1. 创建 zt_li.textContent = '新增：' + zt_text; zt_li.innerHTML += '<span class="zt-del">删除</span>'; zt_list.appendChild(zt_li); // 2. 追加到末尾 // 插到最前面：zt_list.insertBefore(zt_li, zt_list.firstElementChild);
4-2删除节点 + 事件委托（只在父元素上绑定一次）
列表里的项目是后来动态新增的，如果给每个 li 单独绑定事件，新增的 li 就点不动。 把事件绑定在父元素 ul 上，用 event.target 判断点的是谁，这就是事件委托。
zt_list.addEventListener('click', function (e) { if (e.target.classList.contains('zt-del')) { e.target.closest('li').remove(); // 点删除：移除整行 } else { console.log('点击了：' + e.target.textContent); } });

5-2mouseenter / mouseleave 鼠标移入移出
