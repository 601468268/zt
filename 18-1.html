使用 Canvas 2D 绘制姓名“张涛”的文字动画：渐变色文字 + 缩放呼吸效果， 配合上浮粒子与星光背景，全部由 requestAnimationFrame 逐帧驱动。 可通过下方按钮控制动画的开始 / 暂停 / 重置与速度。

一、动画演示（Canvas）
FPS：-- 粒子数：0

动画原理：每一帧先用半透明矩形“盖住”上一帧画面形成拖尾， 再重新绘制星光背景、上浮粒子和渐变文字。 文字颜色由 HSL 色相值随时间递增实现彩虹循环。

二、核心代码
1逐帧动画循环：requestAnimationFrame
// 每秒约 60 次回调，比 setInterval 更省电、更流畅 function loop(timestamp) { var dt = timestamp - lastTime; // 两帧间隔，用于计算速度 lastTime = timestamp; update(dt * speed); // 更新粒子位置、色相、缩放 draw(); // 重绘一帧 requestAnimationFrame(loop); // 请求下一帧 }
2渐变文字“张涛”
// 创建线性渐变，色相随时间旋转，实现彩虹流光效果 var grad = ctx.createLinearGradient(cx - 180, cy - 60, cx + 180, cy + 60); grad.addColorStop(0, 'hsl(' + hue + ',90%,62%)'); grad.addColorStop(0.5, 'hsl(' + (hue + 80) + ',90%,60%)'); grad.addColorStop(1, 'hsl(' + (hue + 160) + ',90%,58%)'); ctx.font = 'bold 150px "Microsoft YaHei", sans-serif'; ctx.textAlign = 'center'; ctx.textBaseline = 'middle'; ctx.fillStyle = grad; ctx.fillText('张涛', cx, cy); // 呼吸缩放通过 ctx.scale 实现
3上浮粒子与拖尾
// 半透明背景矩形代替 clearRect，产生拖尾残影 ctx.fillStyle = 'rgba(11, 16, 32, 0.28)'; ctx.fillRect(0, 0, w, h); // 粒子：随机位置向上漂浮，超出顶部后从底部重生 p.y -= p.vy * step; ctx.globalAlpha = p.alpha; ctx.arc(p.x, p.y, p.r, 0, Math.PI * 2);
三、知识点小结
getContext('2d')

获取绘图上下文，之后所有绘制都通过它完成：fillRect、fillText、arc 等。

requestAnimationFrame

浏览器专门的动画 API，页面切到后台会自动暂停，比 setInterval 定时器更适合逐帧动画。

createLinearGradient

创建线性渐变填充色，配合 HSL 色相旋转可做出流光渐变文字。

globalAlpha / save / restore

控制透明度与状态栈：save 保存当前状态，restore 恢复，避免样式互相污染。
