18-2 基于 Canvas 的全站系统架构图

姓名：张涛  |  学号：24001010104  |  《高级网页设计I》

整个作业站点的前后端结构全部用 Canvas 2D 绘制：自上而下分为 用户层 → 展示层 → 数据/接口层 → 部署层 四个层次， 节点之间用流动虚线箭头表示数据走向。 鼠标悬停到任意节点可高亮该节点并显示说明文字。

一、全站系统架构图（Canvas 绘制）
提示：把鼠标移到节点上看效果

绘制思路：把每个层次当作一个矩形节点（roundRect 圆角矩形 + 渐变填充）， 层与层之间用带箭头的虚线连接，lineDashOffset 随时间递减即可产生“数据流动”效果； 鼠标事件配合坐标判断实现节点高亮。

二、核心代码
1节点数据与布局
// 每层是一个节点：x / y / w / h 决定位置大小，color 决定配色 var nodes = [ { title: '用户层', items: ['PC 浏览器', '手机浏览器'] }, { title: '展示层', items: ['index.html 作品集', '13~17 章作业页面'] }, { title: '数据/接口层', items: ['GitHub Contents API', 'fakestoreapi / dummyjson'] }, { title: '部署层', items: ['GitHub 仓库 main', 'Actions 构建', 'Pages CDN'] } ];
2流动虚线箭头（lineDashOffset）
// 虚线 + 偏移量动画：offset 每帧递减，虚线就“流动”起来 ctx.setLineDash([8, 6]); ctx.lineDashOffset = -offset; // 随时间递减 ctx.beginPath(); ctx.moveTo(x1, y1); ctx.lineTo(x2, y2); ctx.stroke(); drawArrowHead(x2, y2); // 三角形箭头
3鼠标悬停高亮
canvas.addEventListener('mousemove', function (e) { // 把鼠标坐标换算到画布坐标系（画布被 CSS 缩放过） var rect = canvas.getBoundingClientRect(); var mx = (e.clientX - rect.left) * canvas.width / rect.width; var my = (e.clientY - rect.top) * canvas.height / rect.height; hoverNode = hitTest(mx, my); // 命中哪个节点就高亮哪个 });
三、层次说明
① 用户层

访问者通过 PC / 手机浏览器打开 GitHub Pages 上的站点地址，是整个系统的入口。

② 展示层

index.html 作品集首页自动列出各章作业页面（13-3 图标导航、16-4 频道页、17-x 接口演示等），由 HTML / CSS / JavaScript 完成。

③ 数据 / 接口层

作品集首页通过 GitHub Contents API 读取仓库文件列表；17-2 / 17-3 / 17-4 通过 fetch 调用 fakestoreapi、dummyjson 等远程 JSON 接口。

④ 部署层

代码推送到 GitHub 仓库 main 分支后，Actions 自动构建并通过 GitHub Pages CDN 发布，实现“推送即上线”。
