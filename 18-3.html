姓名：张涛  |  学号：24001010104  |  科研方向：知识库驱动的智能问答与检索增强生成（RAG）

使用 SVG 矢量图绘制“基于知识库的智能客服系统”整体架构： 用户请求经过接入层进入智能客服引擎，引擎对问题做 意图识别 → 对话管理 → 知识检索 → 大模型生成（RAG）， 全程依赖知识库层提供 FAQ、向量库、知识图谱等知识来源， 支撑层负责日志、评估与知识运营。图中虚线箭头流动表示数据走向， 鼠标悬停任意层可查看该层的科研要点。

一、系统架构图（SVG 矢量绘制）
鼠标悬停 / 点击左侧任意层次，这里会显示该层的功能与科研关注点。

与 Canvas 版（18-2）不同，本图使用 SVG 矢量格式绘制： 每个节点都是 SVG 元素，放大不模糊、可直接被浏览器搜索与无障碍朗读（aria-label）， 流动虚线由 CSS stroke-dashoffset 动画实现，无需 JavaScript 逐帧重绘。

二、核心代码
1SVG 节点与分组
<!-- 每一层是一个 <g> 分组：矩形底板 + 标题 + 胶囊节点 --> <g class="zt-layer" data-desc="③ 智能客服引擎：..."> <rect x="80" y="352" width="920" height="150" rx="12" stroke="#27ae60"/> <text x="315" y="390">NLU 意图识别</text> </g>
2流动虚线箭头（纯 CSS 动画）
/* stroke-dasharray 画出虚线，dashoffset 随时间偏移产生流动感 */ .zt-flow { fill: none; stroke-dasharray: 9 7; animation: zt-dash 1.2s linear infinite; } @keyframes zt-dash { to { stroke-dashoffset: -32; } }

三、层次说明与科研方向
① 用户层 → ② 接入层

多渠道问答入口与统一网关。科研点：多轮上下文建模、会话状态跟踪（DST）、高并发下的响应时延控制。

③ 智能客服引擎（核心）

NLU 意图识别 + 对话管理 + 检索 + 生成。科研点：意图分类准确率、Embedding 模型选型、Top-K 召回与重排序策略。

④ 知识库层

FAQ、文档向量库、知识图谱、业务库四类知识源。科研点：文档切分（Chunking）策略、向量检索与关键词检索的混合召回、知识自动更新。

⑤ 支撑层 · RAG 评估闭环

离线评估指标：准确率 Accuracy、召回率 Recall、答案忠实度 Faithfulness；在线指标：解决率、转人工率、平均响应时延。评估结果反哺知识库迭代。
