JavaScript 提供两个定时器：setTimeout(函数, 毫秒) 只执行一次； setInterval(函数, 毫秒) 每隔一段时间重复执行。 它们都返回一个数字 id，用 clearTimeout(id) / clearInterval(id) 才能取消， 否则会一直留在内存里执行。本页每个演示都是真实运行的，控制台（F12）有同步输出。

对比项setTimeoutsetInterval

取消方法clearTimeout(id)clearInterval(id)
常见用途延时提示、动画分步、防抖、模拟异步请求时钟、倒计时、轮播图、进度条、轮询接口
注意点回调里的代码在指定时间后进入任务队列忘记 clear 会导致计时器越积越多
两个 id 都是数字（浏览器里从 1 开始递增），实际项目里习惯全局保存，组件卸载时清除。

四、使用定时器要注意的三件事
问题说明
时间不精确定时器的实际间隔受主线程是否空闲影响，只能保证"至少等这么久"，不能保证"正好这么久"。
一定要清除页面跳转、组件销毁、重复点击开始按钮时，如果不 clear 就会叠出多个定时器，速度越跑越快。
回调嵌套难维护多个异步任务先后依赖时，嵌套多层 setTimeout 会形成"回调地狱"，改用 Promise / async / await 更清晰（见 17-6）。
// 用定时器把回调包成 Promise，就能用 await 串起来 function zt_wait(zt_ms) { return new Promise(function (resolve) { setTimeout(resolve, zt_ms); }); } // 之后就可以：await zt_wait(3000); ← 等 3 秒再执行下一步
