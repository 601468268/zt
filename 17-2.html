本页使用原生 fetch（不依赖任何库）请求开放接口 https://fakestoreapi.com：先请求商品列表并渲染成卡片， 点击某张卡片时再按商品 ID 请求详情接口，展示单条数据。 接口已开启跨域（Access-Control-Allow-Origin: *），可直接在浏览器端访问。 打开控制台（F12）可以看到每一次请求的状态码、耗时和返回数据。
一、接口说明与核心代码
1-1本页使用的两个接口
GET https://fakestoreapi.com/products 商品列表（数组） GET https://fakestoreapi.com/products/1 单个商品详情（对象） GET https://fakestoreapi.com/products/category/jewelery 按分类筛选 GET https://fakestoreapi.com/products/categories 全部分类名
返回数据里每条商品包含：id、title、price、description、category、image、rating{rate, count}。
1-2核心代码：async / await + fetch + res.json()
// 请求列表：await 等待响应，res.ok 判断是否成功，res.json() 把响应体转成对象 async function zt_loadProducts() { var zt_res = await fetch('https://fakestoreapi.com/products'); if (!zt_res.ok) { throw new Error('HTTP ' + zt_res.status); } // 404/500 等 var zt_list = await zt_res.json(); // JSON 字符串 → JS 数组 console.log(zt_list.length); // 20 条 } // 请求详情：接口路径里带上 id async function zt_loadDetail(zt_id) { var zt_res = await fetch('https://fakestoreapi.com/products/' + zt_id); var zt_item = await zt_res.json(); } // 一定要用 try / catch 包住，网络错误、接口报错都在这里处理 try { await zt_loadProducts(); } catch (zt_e) { console.error(zt_e.message); }
