本页是「列表与列表详情」的详情页：先从地址栏读取 ?id= 参数（没有就用 1）， 再用 fetch 请求 https://dummyjson.com/products/{id}，按 id 拿到单个商品并展示。 从列表页点击卡片跳转过来时会自动带上对应的 id。图片若加载不到（cdn.dummyjson.com 不通时）， 会显示字母占位块，数据仍然完整。
一、核心代码：读取 URL 参数 + 按 id 请求
// ① 从地址栏取 id：17-3.detail.html?id=5 → "5" var zt_params = new URLSearchParams(location.search); var zt_id = zt_params.get('id') || '1'; // ② 把 id 拼到接口路径上 var zt_url = 'https://dummyjson.com/products/' + zt_id; // ③ 请求并渲染 fetch(zt_url).then(function (res) { if (!res.ok) { throw new Error('HTTP ' + res.status); } // id 不存在时是 404 return res.json(); }).then(function (zt_item) { renderDetail(zt_item); // zt_item.title / price / images ... });
