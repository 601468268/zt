1什么是 SVG 图标

Lucide 的每个图标都是一段 SVG 矢量代码。页面引入 JS 后，lucide.createIcons() 会把带 data-lucide 的标签替换成真正的 <svg> 元素插入到 DOM 中。

<!-- 你写的 -->
<i data-lucide="home"></i>

<!-- JS 执行后，浏览器里实际变成 ↓↓↓ -->
<svg class="lucide lucide-home"
     width="24" height="24" viewBox="0 0 24 24"
     fill="none" stroke="currentColor"
     stroke-width="2" stroke-linecap="round">
  <path d="m3 9 9-7 9 7v11a2 2 0 0 1-2 2H5a2 2 0 0 1-2-2z"/>
  <polyline points="9 22 9 12 15 12 15 22"/>
</svg>

<script src="cdn/lucide/lucide.min.js"></script>
<script>lucide.createIcons();</script>
优点
矢量无损缩放；可用 stroke / fill 精细控制；支持渐变、多色、局部着色；无字体加载闪烁。
注意
需要 JS 渲染（或直接使用 SVG Sprite / 内联 SVG）；图标数量多时 DOM 节点会增加。

3控制大小

SVG 有真实的 width / height，用 CSS 或属性设置即可（矢量缩放不失真）。

<!-- 方式一：CSS 控制（推荐） -->
.lucide { width: 32px; height: 32px; }

<!-- 方式二：直接写属性 -->
<i data-lucide="sun" width="48" height="48"></i>

4控制颜色

Lucide 的 stroke="currentColor" 表示描边色继承父元素的 color，所以改颜色就像改文字一样简单。

#e53e3e
#d69e2e
#38a169
#3182ce
#805ad5
继承父级
<!-- currentColor：跟随父元素 -->
<div style="color:#e53e3e">
  <i data-lucide="heart"></i>
</div>

<!-- 或者直接改 stroke -->
.lucide { stroke: #3182ce; }

5控制描边粗细（SVG 独有）

字体图标的粗细固定，而 SVG 可以用 stroke-width 自由调整线条粗细 —— 这是 SVG 的优势之一。

stroke-width:1
1.5
2（默认）
3
w1 细节
w3 细节
.lucide { stroke-width: 1.5; }

<!-- 或写在标签上 -->
<i data-lucide="circle" stroke-width="3"></i>

6动画（用 CSS 控制）

SVG 是普通 DOM 元素，可以直接用 CSS 动画 / transform 控制。

旋转
加载

弹跳
心跳
@keyframes spin { to { transform: rotate(360deg); } }
.anim-spin { animation: spin 2s linear infinite; }

7SVG 独有能力（字体图标做不到）

因为每个图标都是真实的矢量图形，可以对局部路径单独着色、使用渐变、甚至填充内部。

渐变描边

stroke: url(#渐变ID)

局部着色

用 CSS 选中不同的 path 分别上色

填充内部

fill + stroke 组合

无损缩放

任意尺寸都清晰锐利

<!-- 定义渐变 -->
<svg><defs><linearGradient id="g">...</linearGradient></defs></svg>

<!-- 使用渐变描边 -->
.lucide { stroke: url(#g); }

<!-- 局部着色：选中第 1、2、3 个子元素 -->
.lucide > *:nth-child(1) { stroke: #e53e3e; }
.lucide > *:nth-child(2) { stroke: #3182ce; }

9字体图标 vs SVG 图标

两种方式的核心差异。

对比项 Font Awesome（字体图标） Lucide（SVG 图标）
本质 图标字体文件 + CSS 伪元素 内联 SVG 矢量图形
HTML 写法 <i class="fa-solid fa-house"> <i data-lucide="home">
改大小 font-size / fa-2x width / height
改颜色 color stroke / color
改粗细 不支持 stroke-width 可调
多色 / 渐变 只能单色 支持渐变、局部着色
依赖 CSS + 字体文件（无需 JS） 需要 JS 渲染（或内联 SVG）
加载闪烁 可能有 FOUT 闪烁 无
