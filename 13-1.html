Font Awesome 字体图标

Icon Font · 通过 CSS 伪元素 + 图标字体文件渲染

cdn/font-awesome/css/all.min.css

1什么是字体图标

Font Awesome 把每个图标做成字体里的一个字符。写 <i class="fa-solid fa-house"></i> 时，CSS 用 ::before 伪元素插入该字符，再用图标字体渲染出来。

<!-- HTML：只需要一个空标签 + class -->
<i class="fa-solid fa-house"></i>

/* CSS（all.min.css 内部已定义好） */
.fa-house::before {
  content: "\f015";              /* 图标对应的字符编码 */
  font-family: "Font Awesome 6 Free"; /* 图标字体 */
  font-weight: 900;               /* fa-solid=900 / fa-regular=400 */
}
优点一个字体文件包含全部图标，请求少；可用 color / font-size 直接控制颜色和大小。
缺点只能是单色；浏览器需下载完整字体（体积偏大）；存在字体加载闪烁（FOUT）。

3控制大小

字体图标本质是「文字」，所以用 font-size 就能改大小；Font Awesome 也内置了 fa-xs ~ fa-2xl 和 fa-2x ~ fa-10x 便捷类。

fa-xs
fa-sm
默认
fa-lg
fa-xl
fa-2xl
fa-2x

fa-4x
fa-5x
fa-6x
<!-- 方式一：内置尺寸类 -->
<i class="fa-solid fa-dog fa-3x"></i>

<!-- 方式二：直接写 font-size（因为是字体！） -->
<i class="fa-solid fa-dog" style="font-size: 48px"></i>

4控制颜色

同样因为是「文字」，用 color 就能改颜色，而且可以跟随父元素继承。

#e53e3e
#d69e2e
#38a169
#3182ce
#805ad5
继承父级
<!-- 单独设置 -->
<i class="fa-solid fa-heart" style="color:#e53e3e"></i>

<!-- 跟随父元素 color 继承 -->
<div style="color:#dd6b20">
  <i class="fa-solid fa-sun"></i>
</div>

7堆叠图标 fa-stack

把多个图标叠在一起，常用于「徽章 / 角标」效果。

<span class="fa-stack">
  <i class="fa-solid fa-square fa-stack-2x"></i>   <!-- 底层 -->
  <i class="fa-solid fa-star fa-stack-1x"></i>    <!-- 上层 -->
</span>
