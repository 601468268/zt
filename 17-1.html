JSON（JavaScript Object Notation）是一种轻量级的文本数据交换格式， 用键值对描述数据，语法是 JavaScript 对象字面量的子集，但与语言无关，几乎所有后端语言都能生成和解析。 前端通过 JSON.parse() 把 JSON 字符串变成 JS 对象来用，通过 JSON.stringify() 把对象变回 JSON 字符串发送给后端。 本页所有示例都由 JavaScript 现场解析、生成并渲染，控制台（F12）可查看输出。
一、JSON 的语法规则
1六种合法的值类型
类型示例说明
字符串 string"张涛"必须用双引号，不能用单引号
数字 number20 3.14 -5整数、小数、负数，不能有 NaN / Infinity
布尔 booleantrue false只有小写两种
空值 nullnull表示空，JSON 里没有 undefined
对象 object{"name":"张涛"}键必须是双引号字符串，值可以是任意合法类型
数组 array["HTML","CSS"]用中括号，元素类型可以不同
注意：JSON 不允许 注释（//、/* */）、不允许 末尾多余的逗号、 不允许 单引号、不允许 undefined 和函数。

3-1JSON.parse()：字符串 → 对象
解析后就能用 对象.属性、数组[下标] 正常访问，也可以遍历。
var zt_obj = JSON.parse(zt_jsonText); console.log(zt_obj.student.name); // 张涛 console.log(zt_obj.student.skills); // ["HTML","CSS","JavaScript"]

3-2JSON.stringify()：对象 → 字符串
第二个参数是缩进（数字表示空格数），传 2 就是格式化输出；不传则是一整行紧凑字符串。
JSON.stringify(zt_obj); // 一整行 JSON.stringify(zt_obj, null, 2); // 缩进 2 空格 JSON.stringify(zt_obj, ['name','no']); // 只保留指定键
